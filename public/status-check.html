Quick Setup Guide

  1. Meta Ads: Should work immediately (no OAuth needed)
  2. Google Analytics: Click "Connect Analytics" → Complete OAuth → Test API
  3. Google Ads:
    1. Get Developer Token from Google Ads API Center
    2. Add to .dev.vars: GOOGLE_ADS_DEVELOPER_TOKEN=your-token
    3. Restart application: pm2 restart pinpointer
    4. Click "Connect Google Ads" → Complete OAuth → Test API
